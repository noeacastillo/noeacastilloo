# NOE CASTILLO® — Creative Portfolio

A new bilingual, responsive editorial portfolio built as a lightweight static website. No build tools or API keys are required.

## Preview locally
Open `index.html` in a browser, or from this folder run `python3 -m http.server 8000` and visit http://localhost:8000.

## Publish to GitHub Pages
1. Create a new GitHub repository (for example, `noe-creative-portfolio`).
2. Upload the **contents** of this folder to the repository root.
3. In repository Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)` and save.
4. GitHub will show the new Pages URL once deployed. All links and assets are relative so a project-site URL works.
